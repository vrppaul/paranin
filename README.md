# paranin

> A résumé you can `ssh` into, read in a browser, `curl`, or ask an agent about.

```
ssh paran.in
```

`paranin` is a personal site with one source of facts and many faces: an SSH
TUI, a web page with a vim mode, markdown for agents, a man page for `curl`,
a PDF, and a blog drawn the same way in each of them.

**Status:** being rebuilt on a new foundation. Nothing is deployed yet.
